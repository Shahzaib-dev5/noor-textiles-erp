## Permanent project instructions — Noor Textiles ERP

You are developing a single-company, frontend-only Urdu RTL textile manufacturing and wholesale ERP for Noor Textiles Lahore.

Follow these rules in every development phase:

1. Inspect the existing codebase before making changes.
2. Preserve all completed modules and existing working functionality.
3. Implement only the requested phase.
4. Use React, TypeScript, Tailwind CSS, shadcn/ui and Zustand.
5. Use consistent Urdu labels and right-to-left layouts.
6. Use the existing centralized demo-data store rather than creating separate disconnected mock datasets.
7. All records must use stable IDs and meaningful relationships.
8. CRUD operations must update localStorage state correctly.
9. Never create a button that appears functional but has no action.
10. Validate quantities, inventory balances, costs and transaction states.
11. Do not silently reset existing demo data.
12. Add automated tests for business calculations and critical transactions.
13. Run TypeScript checks, linting, tests and the production build.
14. Fix introduced errors before considering a phase complete.
15. Update IMPLEMENTATION_PROGRESS.md with completed work, outstanding issues and the next phase.
16. Provide a short summary of files changed and functionality implemented.

Do not implement the backend, authentication server, database or real payment gateway.

The application must remain a realistic, interactive frontend demonstration throughout development.
