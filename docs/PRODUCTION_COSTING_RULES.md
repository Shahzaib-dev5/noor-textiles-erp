# Production costing

Money uses integer paisa. Source material cost is frozen on issue with provenance: recorded source cost, current-rate estimate or unpriced. Integer apportionment preserves the original source total across actual consumed material, scrap, remaining WIP and returned meters. Recoverable returns retain value rather than becoming a second expense.

Processed fabric already includes its upstream source and processing costs. These are inherited once through source valuation. Production does not add them again. Component transfer, QC and rework movements transfer existing quantities without duplicating material cost.

Recorded production cost includes recorded consumed/scrap material, posted shared embroidery service bills and approved actual production expenses. Current-rate source valuations and completed/uncompleted unbilled embroidery service remain separately labeled estimates. Missing source prices remain explicitly unpriced. Rework estimates become actual only through one linked approved expense; duplicate references are blocked.

The order exposes its frozen plan estimate, recorded cost, projected cost, absorbed material, scrap, WIP, returns, actual/unbilled embroidery and approved expenses. Per-accepted-complete-component-set cost is unavailable when no complete set exists. Per-target-suit figures are estimates. No realized sales profit is reported and no finished-goods valuation is posted in Phase 8.
